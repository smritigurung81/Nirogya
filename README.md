# 🩺 AI-Based Healthcare Monitoring System using IoT

## 📖 Overview

This project implements an **AI-based healthcare monitoring system** that uses **IoT sensors** to continuously track vital signs such as **heart rate**, **body temperature**, and **oxygen saturation (SpO₂)**.
The system integrates **real-time data transmission**, **AI-powered health assistance**, and **cloud-based synchronization**, creating a comprehensive digital healthcare platform.

## ⚙️ Key Features

### 👨‍⚕️ Multi-User Dashboards

* **Patient Dashboard:** View real-time health metrics and alerts.
* **Doctor Dashboard:** Monitor patients remotely and review health trends.
* **Lab Technician Dashboard:** Access diagnostic data and reports efficiently.

### 💬 AI Chatbot

* Provides **instant medical assistance** for basic health queries.
* Offers **general healthcare recommendations** using AI interaction.

### 🌐 Real-Time IoT Monitoring

* Uses **sensor-based hardware** to continuously track vital signs.
* Automatically uploads data to the cloud for **real-time synchronization**.

### ☁️ Cloud Infrastructure

* Built on **Firebase Realtime Database** and **Cloud Firestore** for:

  * Secure data storage
  * Real-time updates
  * Scalable multi-user access

### ⚡ Early Detection & Remote Consultation

* Supports **early warning alerts** based on abnormal readings.
* Enables **remote consultation** between patients and healthcare professionals.

## 🏗️ System Architecture

1. **IoT Sensors** collect vital data from the user.
2. **Microcontroller** transmits sensor data to Firebase in real time.
3. **Mobile Application** (Android) retrieves and visualizes the data.
4. **AI Chatbot** processes user queries and provides assistance.
5. **Cloud Storage** ensures secure and synchronized data access across all users.

---

## 🔒 Security & Privacy

* All health data is stored securely using Firebase authentication and rules.
* Access control ensures only authorized users (doctor, patient, technician) can view relevant data.
